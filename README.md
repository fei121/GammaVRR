# Cmodel

This repository contains the GammaVRR C/C++ model project.

## Project Layout

- `GammaVRR/code/`: GammaVRR source code and Makefile.
- `GammaVRR/input/`: text configuration, register, and LUT inputs.
- `GammaVRR.sln`: Visual Studio solution.

Large local assets and generated files are intentionally ignored, including Visual Studio caches, build outputs, generated PPM outputs, sample PPM input images, and `AISDR2HDR/` media files.
